# Clinic Flow – App xếp lịch điều trị Khoa YHCT – PHCN

Ứng dụng web tĩnh (một file `index.html`), không cần build.

## Chạy thử trên máy
Mở `index.html` bằng trình duyệt (cần internet để tải Tailwind CDN).

## Dữ liệu
Bản này đã **ẩn họ tên bệnh nhân** (hiển thị "Bệnh nhân BNxxx"). Không đưa họ tên, chẩn đoán hoặc mã ICD của bệnh nhân thật vào repo.

## Triển khai
Netlify: Add new site → Import an existing project → chọn repo này → Build command để trống, Publish directory `.`
